# Pulse

Juego de ritmo para **Windows**: música, aros, distintos modos de teclas, editor de niveles y skins con su propia personalidad.

## Descargar

**[Descargar Pulse para Windows](https://github.com/XhuzZombie/Pulse/releases/latest/download/Pulse-Windows.zip)** · [Todas las versiones](https://github.com/XhuzZombie/Pulse/releases)

Descomprime el ZIP completo y abre **Pulse.exe**. Mantén juntos el ejecutable, `Pulse.pck`, `PulseUpdate.exe` y la carpeta `data`.

## Versiones y actualizaciones

La versión se muestra abajo a la izquierda. Desde **0.35.0**, en **Ajustes → Versiones** puedes elegir **Preguntar antes**, **Automáticamente** o **Manualmente**. Las actualizaciones se instalan al cerrar; conservan canciones, niveles, ajustes y récords.

Si tienes una versión anterior a 0.35.0, descarga manualmente una primera versión con actualizador. Haz una copia de tu carpeta antes de trasladarla; conserva tu carpeta `data` y los ajustes personales.
